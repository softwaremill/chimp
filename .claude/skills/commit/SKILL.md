# Commit Message Structure

Use Conventional Commits prefixes:

- `feat:` - a new feature
- `fix:` - a bug fix
- `docs:` - documentation only
- `test:` - test changes only
- `refactor:` - code change with no behaviour change
- `chore:` - build, tooling, or dependency changes
- `perf:` - a performance improvement

Rules:

- Subject line: prefix + short description. Max 40 characters.
- Describe what the change does, not why.
- Body lines: max 70 characters each. Wrap long lines.
- Keep the body short. Add it only if the subject is not enough.
